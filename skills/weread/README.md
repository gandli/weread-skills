# 微信读书 Skill

微信读书官方 Agent Skill，提供书籍搜索、书架管理、笔记查看等功能。

## 功能列表

| 文件 | 功能 |
|------|------|
| `SKILL.md` | 主技能入口，包含所有指令 |
| `book.md` | 书籍详情、目录、试读 |
| `search.md` | 书籍搜索、热门推荐 |
| `shelf.md` | 书架管理、书籍分组 |
| `notes.md` | 笔记、标注、高亮导出 |
| `review.md` | 书评、想法发布 |
| `profile.md` | 个人资料、书架统计 |
| `readdata.md` | 阅读数据、统计分析 |
| `discover.md` | 发现页、推荐书籍 |

## 使用示例

**搜索书籍：**
```
搜索关于机器学习的中文书籍
```

**查看书架：**
```
显示我的书架
```

**导出笔记：**
```
导出《人类简史》的所有笔记
```

**阅读统计：**
```
查看我本月的阅读统计
```
